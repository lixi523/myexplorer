# MyExplorer 对标 Total Commander：差距分析与升级方案

> 生成：2026-08-08 · 基于 MyExplorer v2.0.0（2.0.0+33）代码库实扫
> 更新：2026-08-08 19:30 · P1-P4 全部完成，新增右键 NC 模式
> 目标：把 MyExplorer 打造成 Total Commander 级别的 Windows 双窗格文件管理器

---

## 一、现状盘点（MyExplorer 已有）

| 领域 | 已实现 |
|---|---|
| 布局 | 恒双窗格 + 中间竖快捷栏（17 按钮，含「查看」）+ 每窗格多标签 |

| 快捷栏 | TC 风格 `.bar` 导入（GBK/UTF-8）、图标提取（exe/dll,idx）、CD/cm_ 命令、**%P%N%T%M%L%S 参数宏** |
| 右键交互 | **NC 扩展选择模式**：右键单击追加多选（不加粗）、拖动扫选（区间补全+边缘自动滚动）、长按>2秒弹菜单、菜单移出/点击外部关闭 |
| 文件操作 | 复制/移动/删除/重命名，**操作队列（暂停/恢复/取消）**，冲突对话框，**自动冲突策略**，原生复制加速（Rust 核心） |
| 压缩 | zip/tar/tar.gz/tar.bz2/tar.xz 浏览/解压/压缩 + **7z 浏览/解压** + **压缩包内编辑**（zip/tar） |
| 预览 | Quick Look 弹窗 + **Ctrl+Q 常驻快速查看面板**（代码高亮/图片/Markdown/PDF/信息面板） |
| 搜索 | 递归搜索 + 实时过滤 + 通配符选组/取消选组 + 全文搜索（Rust 原生） |
| 批量 | 多重重命名（模板 + 查找替换双模式 + [C]/[Nx-y]/[P] token） |
| 比较 | 目录比较模式（compare_controller + diff） |
| 校验 | 单文件校验和 + **.md5/.sha256 清单生成/批量验证** |
| 文件着色 | **文件名文字着色**（扩展名规则 + 文件夹浅灰，行底色不变） |
| 远程 | SFTP 完整读写、SMB 共享发现、WSL 路径 |
| 终端 | 内嵌 PTY 终端（每窗格独立、多标签） |
| 扩展 | FFI 插件系统（自有体系：bar/action/hook） |
| 其他 | 标签系统、隐藏列表、命令面板、文件夹大小扫描、驱动器列表、自动更新、中英双语、主题、唯一实例、最大化启动 |

## 二、差距矩阵（对照 TC 11.5）

### 🔴 核心交互缺失（TC 用户的肌肉记忆区）

| TC 功能 | MyExplorer 状态 | 差距说明 |
|---|---|---|
| **底部 F 键条**（F3查看/F4编辑/F5复制/F6移动/F7建目录/F8删除） | ❌ 无 | 用户明确不做（2026-08-08）：竖快捷栏已集成复制/移动/建目录/删除并新增「查看」按钮，完全替代 F 键条 |
| **底部命令行**（输入命令以当前目录为 cwd 执行，Ctrl+Enter 取选中文件名到命令行） | ❌ 无 | 用户明确不做（2026-08-08）；现有 PTY 终端覆盖命令需求 |
| **快速查看面板 Ctrl+Q**（对侧窗格常驻预览，随选择实时刷新） | ✅ 已实现 | 2026-08-08 完成（QuickViewPanel，对侧窗格底部常驻，复用 Quick Look 渲染组件） |

## 三、升级方案（五个阶段）

> 原则：先补齐 TC 用户的肌肉记忆（快捷键+快速查看），再强化可靠性口碑（队列+校验），然后做批处理深度，最后扩展生态。每阶段独立可发布。

### Phase 1 — TC 核心交互补齐（约 3 天，v1.6）✅ 已完成

> 目标：TC 老用户上手 10 分钟不觉得别扭。

1. **竖快捷栏补「查看」按钮**：对应 TC 的 F3，触发 Quick Look；复用现有 `_openQuickLook`。✅ 2026-08-08 已实现。
2. **快速查看面板 Ctrl+Q**：对侧窗格底部常驻预览条，随活动窗格光标实时刷新；复用 quick_look 渲染组件。✅ 2026-08-08 已实现。

### Phase 2 — 文件操作可靠性（约 2 周，v1.7）✅ 已完成

1. **操作队列**：operation_store 加队列模式，同类 IO 任务串行执行；UI 上任务面板支持排队/暂停/取消。✅ 2026-08-08 已实现（串行队列+暂停/恢复+取消）。
2. **复制后校验开关**：复制任务完成后对目标逐文件 SHA-1 比对。⚠️ **未做（挂起为可选增强）**。
3. **分割/合并**：对话框选分割大小，生成 .001/.002…+.crc；合并时校验 crc。✅ 2026-08-08 已实现（5 档预设+自定义字节数）。
4. **校验文件**：选中多个文件 → 生成 .md5/.sha256 清单；打开清单 → 批量验证出报告。✅ 2026-08-08 已实现（GNU coreutils 格式，4 并发 isolate）。
5. **冲突策略增强**：自动覆盖较旧文件 / 跳过相同大小。✅ 2026-08-08 已实现（设置项，copyWorker 自动决策；⚠️ 运行时生效不落库，见风险）。

### Phase 3 — 搜索与批处理深度（约 2 周，v1.8）✅ 已完成

1. **搜索结果供给列表**：搜索结果灌进当前窗格列表，支持全选后批量操作。✅ 已具备（visibleFiles 直供）。
2. **全文搜索**：内容匹配。✅ 已具备（Rust 原生 searchContent）。
3. **重复文件查找**：扫描范围 → 大小分组 → 哈希 → 分组勾选保留一份，回收站/删除。✅ 2026-08-08 已实现（isolate 后台+进度上报）。
4. **多重重命名增强**：补 [C] 计数器（起始/步长/位数）、[N1-3]/[N-2] 切片、[P] 上级目录名。✅ 2026-08-08 已实现。
5. **文件着色规则**：扩展名 → 颜色映射，**文件名文字着色**（默认：exe 红/图片紫/压缩包棕/文档蓝/媒体绿/文本青），文件夹名浅灰 RGB(233,233,233)，行底色不变。✅ 2026-08-08 已实现（视图菜单入口，可增删/恢复默认；⚠️ 运行时生效不落库）。

### Phase 4 — 归档扩展（约 2 周，v1.9）✅ 已完成

1. **7z 支持**：打包 7za.exe（或链接 7z DLL）进 installer，archive_reader/writer 加 7z 后端；浏览/解压/压缩全通。✅ 2026-08-08 已实现浏览+解压（SevenZipService 自动定位系统 7-Zip）；**压缩仍走 zip/tar（未做 7z 压缩）**。
2. **包内回写**：编辑压缩包内文本文件保存时重新打包（先支持 zip）。✅ 2026-08-08 已实现（zip/tar，ArchiveWriter.mutate replaceSource/replaceInner）。
3. ~~FTP/FTPS~~ —— **用户 2026-08-08 明确不做**（已有 SFTP 覆盖远程文件需求）。
4. **`.bar` 参数宏展开**：导入 TC `.bar` 时把 `paramN` 里的 `%P`（源路径）`%N`（选中文件名）`%T`（目标路径）`%M` 等在 shortcut_runner 执行前展开——**TC 兼容性最关键的一步**。✅ 2026-08-08 已实现（%P/%N/%T/%M/%L/%S + 小写变体）。

### Phase 4.5 — 右键 NC 交互打磨（2026-08-08 完成，随 V2.0 发布）

> TC 的扩展选择模式（NC mode）在 MyExplorer 的落地，经历了 5+ 轮修复（Windows 指针 buttons 值不可靠是主要坑）。

1. **右键单击文件** = 追加多选（高亮但不加粗），不清空已有选择。
2. **按住右键拖动** = 轨迹经过全部选中（含边缘自动滚动 + 快速拖动区间补全不丢行）。
3. **长按右键 >2 秒** = 弹上下文菜单（文件上弹文件菜单，空白处弹背景菜单）；**快速单击任何位置都不弹菜单**（含空白处）。
4. **菜单关闭**：鼠标移出菜单区域、左键/右键点击外部、Esc 均可关闭。
5. **选中样式**：左键/右键选中均不加粗（仅高亮底色）；文件名颜色由着色规则决定。

### Phase 5 — 打磨与生态（持续，v2.x 方向）

1. **自定义内容列**：先做 3 个内置扩展列（图片尺寸、EXE 版本号、音视频时长），验证列渲染管线的可扩展性，再考虑插件化。
2. **插件市场雏形**：插件清单 JSON（GitHub repo 托管）+ 应用内浏览/安装/卸载；现有 FFI 插件体系加沙箱约束文档。
3. **配置导出/导入**：sqlite 设置 + 快捷栏 + 隐藏列表 + 书签 → 单个 .zip 配置包，一键迁移。
4. **性能专项**：10 万文件目录的滚动流畅度（虚拟列表验证）、大目录着色渲染开销、内存占用审计。
5. **TC 迁移工具**：读取 wincmd.ini + usercmd.ini + .bar，一键导入书签/命令/按钮，降低迁移成本。

## 五、不做清单（明确排除）

1. ❌ 不兼容 TC 原生插件格式（WCX/WFX/WDX/WLX 是 32/64 位 DLL 加 C ABI，绑定成本极高且文档老旧）——走自有插件体系。
2. ❌ 不做并行口/USB 直连线传输（历史功能）。
3. ❌ 不做 Linux/macOS 版（项目定位 Windows-only）。
4. ❌ 不做完整 EXE 反编译级「内嵌查看器插件」（WLX 生态），Quick Look 渲染组件已覆盖主流格式。
5. ❌ **不做底部命令行**（用户 2026-08-08 明确排除；内嵌 PTY 终端已覆盖命令行需求）。
6. ❌ **不做底部 F 键条**（用户 2026-08-08 明确排除；竖快捷栏已集成复制/移动/建目录/删除/查看，完全替代）。
7. ❌ **不做 F4 内置编辑器**（用户 2026-08-08 明确排除；依赖外部编辑器）。
8. ❌ **不做分支视图 Ctrl+B**（用户 2026-08-08 明确排除）。
9. ❌ **不做 WebDAV**（用户 2026-08-08 明确排除）。
10. ❌ **不做 FTP/FTPS**（用户 2026-08-08 明确排除；已有 SFTP 覆盖远程文件需求，不必为老旧 FTP 场景投入 Rust 核心改动）。
