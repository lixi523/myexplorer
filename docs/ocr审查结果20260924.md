### Top Issues

1. **测试假阳性与低效断言导致质量防线失效**
   集成测试中大量使用“静默返回”而非断言失败，导致CI环境无法捕捉到缺失文件或路径错误。`test/integration/fs/shortcut_icon_test.dart` 中当 INI 文件不存在时直接 `return`，被视为通过；`test/unit/platform/app_dirs_test.dart` 依赖 PowerShell 且未检查执行结果，`tearDown` 中吞掉所有异常，掩盖环境污染。这些缺陷使得核心文件系统和平台逻辑的测试覆盖率形同虚设。

2. **Win32 FFI 交互的内存安全与类型匹配缺陷**
   `lib/core/platform/win32_attributes.dart` 中存在多处底层风险：全局变量 `_kernel32` 的初始化缺乏原子性检查；`GetFileAttributesW` 返回 `DWORD`（无符号32位）但 Dart 侧声明为 `int`（有符号64位），导致 `0xFFFFFFFF`（失败值）被错误解析为巨大正数；`ShellExecuteW` 参数拼接未转义路径中的特殊字符（如 `"`、`\`），存在命令注入风险。

3. **Rust FFI 边界的健壮性不足**
   `rust/myexplorer_core/src/util.rs` 中 `null_with_len` 未验证 `out_len` 指针的有效性和对齐性；`d.as_millis()` 转 `i64` 在极端时间戳下静默截断；`modified()` 错误时返回 `0`（Epoch时间）而非明确的“未知”状态，调用方易将“无法获取”误读为“1970年修改”。

4. **路径解析与模型类的语义错误及缺失**
   `lib/features/containers/wsl_path.dart` 中 `WslPath` 缺少 `==`/`hashCode` 实现，作为 Map key 时退化为引用相等；`rest` 字段为 `sublist` 视图，外部误操作会导致内部状态破坏。`lib/features/locations/location_uri.dart` 处理空主机名的 SMB 路径时生成 `\\share`（本地Loopback），引发非预期的重定向。

5. **并发与资源生命周期管理缺陷**
   `lib/features/command_palette/command_usage_store.dart` 的 `rankedIds` 排序在 `_lastUsed` 为 null 时逻辑退化；`lib/features/navigation/select_pattern_dialog.dart` 创建的 `TextEditingController` 从未 `dispose`，对话框关闭后存在内存泄漏及 Flutter 断言风险。`scripts/mock_update_server.py` 在 `ThreadingHTTPServer` 下存在 TOCTOU 竞态，`getsize` 与 `open` 之间的文件状态变更未处理。

6. **脚本供应链与构建完整性风险**
   `scripts/build_myexplorer_core_windows.ps1` 下载外部二进制后未校验 SHA256，存在供应链攻击风险；`$ErrorActionPreference = "Stop"` 对原生外部命令（如 `cargo`）无效，编译失败会被静默忽略。`scripts/capture_screenshot.ps1` 中 GDI 对象（Bitmap/Graphics）缺乏 `try/finally` 保护，异常发生时导致句柄泄漏。

7. **UI 模型层防御性编程缺失**
   `lib/core/models/file_operation.dart` 中当 `sources` 为空列表时，调用 `.first` 会抛出 `StateError` 导致标题渲染崩溃；当 `destination` 为 `null` 时，显示为“Compressing to ”（无目标名），用户体验受损且掩盖了数据异常。

8. **本地化与状态语义映射错误**
   `lib/core/models/file_operation.dart` 通过字符串替换解析本地化文本（`replaceFirst(' ()', '')`），对中文全角括号处理失效；复用“暂停”状态文案表示“冲突待决”，在无冲突的暂停场景下向用户展示错误的业务提示。

### Module Hotspots

*   **`lib/core/platform/`**：高危热点。集中在 Win32 API 的互操作中，涉及非原子并发、位宽不匹配、内存分配边界及命令注入，影响应用底层稳定性与安全。
*   **`test/`**：质量防线热点。集成与单元测试中存在大量“静默通过”、依赖外部 PowerShell/特定构建配置、以及无断言的提前返回，导致无法有效拦截回归缺陷。
*   **`scripts/`**：构建与运维热点。PowerShell 和 Python 脚本中普遍缺乏资源清理（`try/finally`）、供应链校验（哈希验证）以及对外部进程执行状态的显式检查。
*   **`lib/features/locations/` & `lib/features/containers/`**：路径模型热点。`WslPath` 和 `LocationUri` 在处理边界情况（空主机名、非法子段、共享引用）时存在逻辑缺陷，且模型类缺少标准的值比较能力。

### Cross-Cutting Concerns

1.  **错误处理与静默失败（Silent Failures）**
    跨文件普遍存在“异常被吞没”或“边界条件直接返回”的模式，而非抛出可观测的异常或返回错误码。
    *   测试层：`test/integration/fs/shortcut_icon_test.dart` 文件缺失时静默返回；`test/unit/platform/app_dirs_test.dart` `tearDown` 中 `catch (_) {}`。
    *   脚本层：`scripts/build_myexplorer_core_windows.ps1` 忽略 `cargo` 等外部命令的退出码；`scripts/capture_screenshot.ps1` 未校验 `Process.runSync` 结果。
    *   代码层：`rust/myexplorer_core/src/util.rs` 中 `modified()` 错误时静默返回 0。

2.  **资源生命周期与清理缺失（Resource Leaks）**
    对象创建后未提供或执行配套的销毁/清理逻辑，尤其在非正常退出路径下。
    *   Dart UI：`lib/features/navigation/select_pattern_dialog.dart` 中 `TextEditingController` 未 dispose。
    *   文件系统/临时文件：`lib/utils/ini_file.dart` 中 `.tmp` 文件在重命名失败时无 `try/finally` 清理，遗留孤儿文件。
    *   GDI/系统资源：`scripts/capture_screenshot.ps1` 中 Bitmap/GDI 句柄在异常时未释放。

3.  **外部输入与用户数据的校验不足（Unsafe Data Handling）**
    在处理来自外部（文件系统、用户输入、网络）的数据时，缺乏格式白名单或合法性校验，直接拼接或解析。
    *   `lib/core/settings/color_rule_store.dart` 未校验扩展名输入是否包含空格或特殊字符。
    *   `lib/core/platform/win32_attributes.dart` 将用户路径直接拼接进 `ShellExecuteW` 参数而未转义。
    *   `docs/examples/plugins/sevenzip/init.lua` 将用户输入的文件名直接拼入 7z 命令行，存在命令注入风险。
    *   `lib/features/locations/location_uri.dart` 解析 SMB 用户名时未过滤控制字符。

4.  **边界条件与空值防御缺失（Null/Empty Bounds）**
    在空集合、空字符串或 null 输入下缺乏防御性处理，导致潜在崩溃或隐式错误行为。
    *   `lib/core/models/file_operation.dart` `sources` 为空时调用 `.first` 崩溃。
    *   `lib/features/locations/location_uri.dart` 空主机名导致生成非法的 UNC 路径。
    *   `lib/features/command_palette/command_usage_store.dart` 在 `_lastUsed` 为 null 时排序比较器退化。
